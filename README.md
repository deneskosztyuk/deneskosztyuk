## Featured Projects

### Warehouse Robotics Dashboard
> **[Live Demo →](https://warehouse-dashboard-rust.vercel.app/)** · Next.js 14 · React Three Fiber · TypeScript · Vercel

Real-time 3D fleet monitoring system for autonomous warehouse robots.

- Interactive 3D warehouse visualization with React Three Fiber / Three.js
- Live robot status tracking, battery management, and task coordination
- Dynamic efficiency graphs and fleet utilization metrics
- Deployed on Vercel with automatic scaling

---

### ESP32 IoT Telemetry Dashboard
> C++ · ESP32 · Python · Flask · Matplotlib

End-to-end IoT system for environmental data acquisition and real-time visualization.

- ESP32 firmware reading BME280 sensors (temperature, humidity, pressure) over I2C
- HTTP/REST wireless data streaming over WiFi
- Flask backend for data ingestion and API management
- Live Matplotlib dashboard with Tkinter GUI
